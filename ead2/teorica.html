Perguntas

O corpo da requisição está correto?

É necessário converter o JSON com JSON.sringify({:nome "ana"}). O body está tentando enviar um objeto java de forma direta.

Falta algum header?

Sim falta o header. "'Content-type': 'applicaton/json'" para o servidoe php saber como interpretar o body da requisição

Como o PHP deveria ler essa entrada?

No PHP, o body é interpretadoo através de "file_get_contents('php//input') e json_decode()", em vez de $POST.

Como tratar erro HTTP?

O "try..catch" pega os erros de rede, tipo cservidor fora di ar. O "if (!resposta.ok) " pega os erros do servidor, tipo página não encontrada(404) ou erro interno(500)
